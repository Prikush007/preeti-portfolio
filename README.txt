PREETI PORTFOLIO REFRESH
========================

Files:
- index.html
- css/style.css
- js/script.js

How to use:
1. Make a backup copy of your existing Preeti-Portfolio folder first.
2. Copy index.html, css/style.css, and js/script.js from this refresh into your existing project, replacing those three files.
3. Keep your existing images folder and any resume/certificate files.
4. Open the folder in VS Code and open index.html in your browser (or use Live Server if available).

Notes:
- The hero uses a designed initials avatar (PK), so it does not require a profile photo.
- The GitHub project buttons currently lead to your GitHub profile. Replace each with its specific repository URL when you publish it.
- Certificate cards are descriptive; add your certificate URLs/PDFs when ready.
- The contact form opens the visitor's default email app. It does not send messages through a server.
- The page uses Google Fonts when internet is available and falls back to system fonts when offline.
- Check semester, certification names, project status, and all links before publishing.
